Weir で <kbd>⌘/</kbd> を押すと、自分の割り当てを含む一覧が開きます。キーを変えるには **設定 → キーボード** を開きます。

## エージェントとレビュー

| キー | 動作 |
|---|---|
| <kbd>⌘J</kbd> / <kbd>⇧⌘J</kbd> | 次 / 前の要対応へ移動 |
| <kbd>⌃⌘J</kbd> | 要対応の一覧を表示 |
| <kbd>⌘⏎</kbd> | バーの主な操作（確認済みにする、再開など） |
| <kbd>⌥⌘R</kbd> | レビュー |
| <kbd>⌥⌘J</kbd> | 最新のターンをレビュー |
| <kbd>⌥⌘I</kbd> | 変更パネル |

## ワークツリーとタブ

| キー | 動作 |
|---|---|
| <kbd>⌘N</kbd> | 新規ワークツリー |
| <kbd>⌘O</kbd> | フォルダを開く |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | 次 / 前のワークツリー |
| <kbd>⌃⌘1</kbd>…<kbd>⌃⌘9</kbd> | N 番目のワークツリーへ移動 |
| <kbd>⌘T</kbd> | 新規タブ |
| <kbd>⇧⌘]</kbd> / <kbd>⇧⌘[</kbd> | 次 / 前のタブ |
| <kbd>⌘1</kbd>…<kbd>⌘9</kbd> | N 番目のタブへ移動 |
| <kbd>⇧⌘A</kbd> | 開いているタブを表示 |

## 閉じる

| キー | 動作 |
|---|---|
| <kbd>⌘W</kbd> | ペイン、または前面のレビューや設定を閉じる |
| <kbd>⌥⌘W</kbd> | タブを閉じる |
| <kbd>⇧⌘W</kbd> | ウインドウを閉じる（エージェントは動き続けます） |

## その他

| キー | 動作 |
|---|---|
| <kbd>⇧⌘P</kbd> | コマンドパレット |
| <kbd>⌘P</kbd> | クイックオープン |
| <kbd>⌥⌘O</kbd> | すべてのプロジェクト |
| <kbd>⌥⌘S</kbd> | スクラッチ |
| <kbd>⇧⌘N</kbd> | 通知履歴 |
| <kbd>⌘,</kbd> | 設定 |
| <kbd>⌘/</kbd> | キーボードショートカット |
