## 一覧

**要対応** には、すべてのプロジェクトで対応を待っているものが到着順に並びます。承認、質問、停止、未確認のターンです。

承認、回答、応答、サインインを待つ状態は、疑問符の入ったオレンジの丸です。停止は感嘆符の入った赤い丸、実行中は灰色の弧、未読は中央に点のある青い輪です。**要対応** の件数は、応答待ちや停止を含むとオレンジ、未読だけなら青になります。メニューバーでは、前者を大きな塗りつぶしの丸で、未読だけのときは小さな点で示します。別のウインドウにある項目には、重なったウインドウのアイコンと場所を示すラベルが付きます。

| キー | 動作 |
|---|---|
| <kbd>⌘J</kbd> | 次へ移動 |
| <kbd>⇧⌘J</kbd> | 前へ移動 |
| <kbd>⌥⌘J</kbd> | 一覧を開く |

![要対応の一覧。到着順に 7 件並び、最後の行に回答ボタンがあります](../../../../assets/captures/docs/needs-attention-ja.png)

ファイルを変更したターンは、[確認済みにする](/ja/docs/review/#ターンを確認済みにする)まで一覧に残ります。

すべてのプロジェクトのワークツリーを状態ごとに見るには、<kbd>⇧⌘O</kbd> で **すべてのプロジェクト** を開きます。

## 承認に答える

依頼は、ペインがどこにあっても、答えるまで Weir が預かります。答えるには承認カードを使います。カードは次のどこからでも開けます。

| 場所 | 開き方 |
|---|---|
| エージェントのペインの下のバー | **回答…** を選ぶか、<kbd>⌘⏎</kbd> を押します |
| **要対応** の一覧 | **回答…** を選びます |
| サイドバーのワークツリーの行 | カーソルを合わせて **回答…** を選びます |
| **すべてのプロジェクト** | ワークツリーの **回答…** を選びます |
| ほかのアプリが前面にあるときのメニューバー | 短く影響の小さいシェルコマンドの依頼には、その場で答えられます。それ以外は **回答…** で Weir を開きます |

カードは、**回答…** を選んだ場所のそばに、同じウインドウで開きます。一覧やサイドバーの行から開いたときは、カードを開いている間、その行が強調されたままになります。

ペインに移動しても、依頼は Weir が預かったままです。ペインを離れたあとも、カードで答えられます。Claude Code と OpenCode はペインにも自分のプロンプトを出します。カードとプロンプトのうち、先に答えたほうが使われます。Codex がプロンプトを出すのは、**ターミナルで回答** を選んだときか、時間切れになったときです。

![承認カード。エージェントが実行したいコマンドと残り時間が表示され、ターミナルで回答、拒否、今回のみ許可のボタンが並びます](../../../../assets/captures/docs/approval-ja.png)

カードかバーの **⋯** メニューで **ターミナルで回答** を選ぶと、そのペインに移動して、依頼をエージェントのプロンプトに渡します。そのあとはプロンプトで答えます。カードには残り時間が表示され、時間切れになった依頼にはターミナルで答えます。

Weir を終了すると、預かっている依頼はすべてエージェントのプロンプトに渡ります。終了の直前に選んだ答えは、そのまま一度だけエージェントに届きます。

Weir に「常に許可」の選択肢はなく、エージェントの設定にも何も書き込みません。常に許可したいときは、エージェントのプロンプトで選んでください。

Codex の質問には、常にターミナルで答えます。

Antigravity には承認カードがありません。承認にも質問にも常にそのプロンプトで答え、Weir には待っていることだけが表示されます。サブエージェントの承認待ちは Weir に表示されないことがあります。`agy` に Blocked と表示されるので、<kbd>⌃K</kbd> で承認します。

Kiro にも承認カードはありません。承認には Kiro のプロンプトで答え、Weir には待っていることだけが表示されます。

OpenCode では、「常に許可」を選ぶことと質問に答えることは、そのプロンプトでしかできません。

Weir は OpenCode のタブをそれぞれ別に見守ります。表示していないタブで起きた承認待ちや失敗も、ここに届きます。そこへ移動するか、その依頼で **ターミナルで回答** を選ぶと、そのタブが前面に出ます。ペインのバッジには、そのペインのタブのうち、最も急ぎの状態が表示されます。

## 止まったとき

API エラーや利用上限、終了などでエージェントが止まると、ペインの下のバーに次の項目が表示されます。

- **同じ会話で再開**：止まったところから続けます。
- **途中までの変更を表示** と **新しい会話で開始**：**⋯** メニューにあります。

利用上限で止まったときは、上限が解除されたら通知を受け取ることもできます。Antigravity は上限をエラーの文面でしか伝えません。Weir が読み取れない文面なら通常の停止として表示され、解除時刻が読めなければ通知は選べません。

OpenCode は複数のサービスとモデルを使うので、そのうち 1 つが上限に達しても、ほかの OpenCode のペインには上限の表示が付きません。モデルを変えれば続けられることがあるので、停止には通知ではなく **再開** が表示されます。

## 確認なしで動くエージェント

すべての操作を確認なしで実行する設定のエージェントでは、ペインのヘッダーに警告アイコンが表示されます。アイコンにカーソルを合わせると **確認なしで実行** と表示され、VoiceOver もヘッダーとともに同じ警告を読み上げます。OpenCode では、`--auto` で起動したときにだけアイコンが表示されます。設定ファイルで自動承認にしている場合は、Weir がその設定を読み取れないため、アイコンは表示されません。
