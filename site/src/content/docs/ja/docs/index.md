Weir は、Claude Code と Codex を並行して動かすための Mac アプリです。どのエージェントが待っているか、1 回分の作業（ターン）ごとに何が変わったかがすぐ分かります。

![Weir のウインドウ。左にワークツリー、中央にターミナル、右に各ターンの変更。](../../../../assets/captures/hero-dark.png)

エージェントの画面はいつものターミナルのままで、指示もこれまでどおりエージェントのプロンプトに入力します。Weir はそれをペインで動かして状態を追うアプリで、エディタでもエージェントでもありません。

Weir はプレアルファ版です。設定やデータの形式は、リリースごとに変わることがあります。

## はじめに

1. [Weir をインストールします](/ja/docs/install/)。
2. [最初のエージェントを動かして、ターンをレビューします](/ja/docs/quick-start/)。
3. 画面の言葉が分からないときは、[基本の考え方](/ja/docs/concepts/)を見てください。

## 目的から探す

- [変更をレビューする](/ja/docs/review/): ターンを読む、コメントする、コードを元に戻す。
- [要対応と承認](/ja/docs/needs-attention/): 対応を待っているエージェントへ移動する。
- [キーボードショートカット](/ja/docs/shortcuts/): 既定のキー。
- [困ったときは](/ja/docs/troubleshooting/): 様子がおかしいとき。
- [プライバシーとデータ](/ja/docs/privacy/): Weir が送るもの、保存するもの。

ウインドウの各部分の詳しい説明は、GitHub の[ユーザーガイド](https://github.com/nek0der/weir/blob/main/docs/user-guide.md)（英語）にあります。
