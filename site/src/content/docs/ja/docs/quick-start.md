1 つのタスクを最初から最後まで進めます。[インストール済みの Weir](/ja/docs/install/)、Git リポジトリ、サインイン済みの Claude Code、Codex、Antigravity のいずれかが必要です。

## 1. プロジェクトを開く

<kbd>⌘O</kbd> を押して、リポジトリのフォルダを選びます。サイドバーにプロジェクトとして表示され、最初の行がそのフォルダです。

## 2. タスク用のワークツリーを作る

<kbd>⌘N</kbd> を押して **新規ワークツリー** を開きます。新しいブランチか既存のブランチと、開くエージェントを選び、<kbd>⌘⏎</kbd> で作成します。

ワークツリーには専用のフォルダとサイドバーの行ができるので、このタスクのファイルが他の作業と混ざりません。

`.env` など Git が無視するファイルは、**プロジェクト設定** で選ばない限りコピーされません。

## 3. 最初の指示を出す

エージェントがターミナルで開きます。初めてのフォルダでは、信頼するかどうかをエージェントが尋ねることがあります。そのあと、いつもどおりプロンプトに指示を入力してください。

サイドバーの行とペインの下のバーに、エージェントの様子が表示されます。画面が勝手に切り替わることはないので、動かしたまま別の作業をしていて大丈夫です。

## 4. 呼ばれたら見に行く

エージェントが承認を求めたとき、質問したとき、止まったとき、ターンを終えたときは、**要対応** に入ります。<kbd>⌘J</kbd> で移動します。

承認と質問には、エージェントのプロンプトで答えます。他の答え方は[要対応と承認](/ja/docs/needs-attention/)を見てください。

## 5. ターンをレビューする

ファイルを変更したターンには、<kbd>⌘J</kbd> で移動するとレビューのタブが開きます。すでにそのペインにいるときは <kbd>⌥⌘R</kbd> を押します。

直してほしいところがあれば、行番号をクリックして <kbd>C</kbd> を押し、コメントを書いて **追加** を選びます。そのあと **コメント *n* 件を挿入** を選びます。コメントが 1 つのメッセージとしてエージェントの入力欄に入るので、<kbd>Return</kbd> を押して送ります。押すまでは送られません。

## 6. 確認済みにする

読み終えたら <kbd>⌘⏎</kbd> で **確認済みにする** を実行します。ターンが **要対応** から消え、レビューが閉じます。

そのターンの変更が要らないときは、代わりにバーの **⋯** メニューにある **このターンの前にコードを復元…** を使います。未確認のターンが複数あるときは、**T1 の前にコードを復元…** のように最初のターンの番号で表示されます。確認済みにした後は、変更パネル（<kbd>⌥⌘I</kbd>）のカードに同じ操作があります。詳しくは[変更をレビューする](/ja/docs/review/)を見てください。

## 次に読むもの

<kbd>⌘/</kbd> ですべてのショートカットを確認でき、<kbd>⇧⌘P</kbd> で名前からコマンドを探せます。別のタスクを同時に進めるときは、手順 2 に戻ります。
