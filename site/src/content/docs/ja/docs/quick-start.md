1 つのタスクを最初から最後まで進めます。必要なものは、[インストール済みの Weir](/ja/docs/install/)、Git リポジトリ、そして Claude Code、Codex、Antigravity、OpenCode、Kiro のうちいずれか 1 つのエージェントです。エージェントには、あらかじめサインインしてください。

## 1. プロジェクトを開く

<kbd>⌘O</kbd> を押して、リポジトリのフォルダーを選びます。サイドバーにプロジェクトとして表示され、最初の行がそのフォルダーです。

## 2. タスク用のワークツリーを作成する

<kbd>⌘N</kbd> を押して **新規ワークツリー** を開きます。新しいブランチか既存のブランチと、開くエージェントを選び、<kbd>⌘⏎</kbd> で作成します。

ワークツリーには専用のフォルダーとサイドバーの行ができるので、このタスクのファイルがほかの作業と混ざりません。

`.env` など Git が無視するファイルは、**プロジェクト設定** で選ばない限りコピーされません。

## 3. 最初の指示を出す

エージェントがターミナルで開きます。初めてのフォルダーでは、信頼するかどうかをエージェントが尋ねることがあります。そのあと、いつもどおりプロンプトに指示を入力してください。

サイドバーの行とペインの下のバーに、エージェントの様子が表示されます。Weir が画面を自動で切り替えることはないので、エージェントを動かしたまま別の作業を続けられます。

## 4. 呼ばれたら見に行く

エージェントが承認を求めたとき、質問したとき、止まったとき、ターンを終えたときは、その項目が **要対応** に入ります。<kbd>⌘J</kbd> で移動します。

承認と質問には、ペインの下のバーにある **回答…** か <kbd>⌘⏎</kbd> で承認カードを開いて答えます。Codex と OpenCode の質問と、Antigravity と Kiro の承認と質問には、エージェントのプロンプトで答えます。ほかの答え方は[要対応と承認](/ja/docs/needs-attention/)を見てください。

## 5. ターンをレビューする

ファイルを変更したターンには、<kbd>⌘J</kbd> で移動するとレビューのタブが開きます。すでにそのペインにいるときは <kbd>⌥⌘R</kbd> を押します。

直してほしいところがあれば、行番号をクリックして <kbd>C</kbd> を押し、コメントを書いて **追加** を選びます。そのあと **コメント *n* 件を挿入** を選びます。コメントが 1 つのメッセージとしてエージェントの入力欄に入るので、<kbd>Return</kbd> を押して送ります。押すまでは送られません。

## 6. 確認済みにする

読み終えたら <kbd>⌘⏎</kbd> で **確認済みにする** を実行します。ターンが **要対応** から消え、レビューが閉じます。

そのターンの変更が要らないときは、代わりにバーの **⋯** メニューにある **このターンの前にコードを復元…** を使います。未確認のターンが複数あるときは、このメニュー項目が **T1 の前にコードを復元…** のように、最初のターンの番号で表示されます。確認済みにしたあとは、変更パネル（<kbd>⌥⌘I</kbd>）のカードに同じ操作があります。詳しくは[変更をレビューする](/ja/docs/review/)を見てください。

## 次に読むもの

<kbd>⌘/</kbd> ですべてのショートカットを確認でき、<kbd>⇧⌘P</kbd> で名前からコマンドを探せます。別のタスクを同時に進めるときは、手順 2 に戻ります。
