## ターンが要対応から消えない

ファイルを変更したターンは、確認済みにするまで残ります。<kbd>⌘⏎</kbd> で **確認済みにする** を実行してください。[変更をレビューする](/ja/docs/review/#ターンを確認済みにする)も見てください。

## 承認がカードに出ない

カードは自動では開きません。ペインが見えていない依頼は、**要対応** の一覧にある **回答…** か、サイドバーのワークツリーの行にカーソルを合わせると出る **回答…** で開きます。見えているペインの依頼はエージェントのプロンプトに出るので、そこで答えてください。

すべての承認がプロンプトに出るときは、**システム設定 → 一般 → ログイン項目と機能拡張** で Weir のサービスがオンか確かめてください。Team ID なしで自分でビルドしたものには、承認サービスがありません。

## 実行中や承認待ちの表示が消えない

tmux の中で起きることがあります。Claude Code のターンを <kbd>Esc</kbd> や <kbd>Ctrl+C</kbd> で止めたり、ダイアログで拒否したりしても、そのペインで次のプロンプトを送るまで Weir に伝わりません。次のプロンプトを送れば消えます。

`CLAUDE_CODE_DISABLE_TERMINAL_TITLE` を設定している場合は、tmux の外でも同じことが起きます。

## Claude Code のプラン使用量が出ない

Claude Code は使用量をステータスラインにしか渡さないので、自分のステータスラインが必要です。Claude Code で `/statusline` を実行して設定してください。Weir のペインで次に返答があったときに表示されます。

## Codex のプラン使用量が出ない

ChatGPT で Codex にサインインしていると表示されます。Weir は `~/.codex` のアカウントを読むので、シェルで `CODEX_HOME` を設定していても、読むアカウントは変わりません。

## Antigravity のプラン使用量が出ない

Antigravity は使用量をステータスラインにしか渡さないので、自分のステータスラインが必要です。`agy` で `/statusline` を実行して設定してください。Weir のペインで次に返答があったときに表示されます。`--settings` を自分で渡して起動した場合は表示されません。

## Antigravity がずっと作業中のままになる

自分で起動した tmux の中で起きることがあります。そこでは `agy` が状態を知らせないので、生成を止めたり質問を取り消したりしても、次のプロンプトを送るまで作業中のままです。許可の確認も、待ちとして表示されません。Weir が `agy` を tmux の中で動かすことはないので、ペインで直接起動すれば起きません。

## Antigravity の状態が Weir に出ない

Weir のペインで最初に `agy` を起動したときに、`~/.gemini/config/plugins/weir` にプラグインを置きます。同じ名前のフォルダーが `.weir-managed` ファイルなしですでにあると、Weir は触れません。そのフォルダーを別の場所に移してください。`agy plugin disable weir` を実行していた場合は、`agy` でプラグインを有効に戻してください。

## 行に PR の状態が出ない

`gh` か `glab` を入れて、プロジェクトのリモートにサインインしてください。**PR を作成** には `gh` が必要なので、GitLab のマージリクエストは Weir からは作れません。

## 新規ワークツリーに未コミットの変更を持ち込めない

Git 2.40 以降が必要です。ワークツリーでマージやリベースの途中のとき、コンフリクトがあるとき、スパースチェックアウトを使っているときも、何も作らずに止まります。先にそれを済ませるか、変更を持ち込まずに作ってください。

Git が無視するファイルは持ち込まれません。`.env` などをコピーするには、**プロジェクト設定** で選んでください。

## ターンの最初や最後でプロンプトが止まる

Weir はターンの最初と最後にスナップショットを取ります。これが止まると、プロンプトが最大 10 分止まることがあります。何度も起きるときは報告してください。

## 古いターンが消えた

古いターンは自動で削除されます。長く残すには、**設定 → 詳細設定 → ターンの記録** で日数と会話ごとの件数を増やしてください。上限の一覧は[プライバシーとデータ](/ja/docs/privacy/#データの場所)にあります。

## それでも解決しないとき

まだ動かないことの一覧は、[Known limitations](https://github.com/nek0der/weir/blob/main/docs/known-limitations.md)（英語）にあります。

[Discussions](https://github.com/nek0der/weir/discussions) で質問するか、[Issue](https://github.com/nek0der/weir/issues) を作ってください。Weir と macOS のバージョン、使っているエージェント、期待した動きを書いてもらえると助かります。開発は 1 人で行っているので、返信に時間がかかることがあります。

セキュリティの問題は Issue にせず、[セキュリティポリシー](https://github.com/nek0der/weir/blob/main/SECURITY.md)に従って報告してください。
