## プロジェクト

Weir で開いた Git リポジトリです。1 つのウインドウに 1 つのプロジェクトを表示し、サイドバーにはすべてのプロジェクトが並びます。

## ワークツリー

`git worktree` で作る、ブランチごとの別のフォルダです。Weir ではサイドバーに 1 行ずつ表示されます。タスクごとにフォルダを分けられるので、エージェントどうしがファイルを上書きし合うことがありません。

## ターン

エージェントの作業の 1 回分です。プロンプトを送ってから、エージェントが止まって次の指示を待つまでを指します。Weir はターンの最初と最後にワークツリーのスナップショットを取るので、そのターンの変更を表示でき、ターンの前のコードにも戻せます。

ターンには T1、T2 のように番号が付きます。

## 確認済みの線

会話のどこまでレビューしたかを示す線です。線より前のターンは確認済み、後のターンは未確認です。ファイルを変更したターンは、**確認済みにする** で線を進めるまで **要対応** に残ります。何も変更しなかったターンは、ペインを見た時点で確認済みになります。

## 要対応

すべてのプロジェクトで対応を待っているものをまとめた一覧です。承認、質問、停止、未確認のターンが入ります。[要対応と承認](/ja/docs/needs-attention/)を見てください。

## スコープ

レビューに表示する範囲です。1 つの会話の未確認のターン、ワークツリーのすべての未確認のターン、1 つのターン、未コミットの変更、ベースブランチとの差分から選びます。

## ハンク

差分の中の、変更された行のまとまりです。まわりの変更されていない行も含みます。レビューではハンクごとに破棄できます。

## スクラッチ

どのプロジェクトにも属さないターミナルです。<kbd>⌥⌘S</kbd> で開きます。
