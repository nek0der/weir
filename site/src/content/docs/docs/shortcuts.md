Press <kbd>⌘/</kbd> in Weir to see the full list with your own bindings. To change a key, open **Settings → Keyboard**.

## Agents and review

| Key | Action |
|---|---|
| <kbd>⌘J</kbd> / <kbd>⇧⌘J</kbd> | Next / previous item that needs you |
| <kbd>⌃⌘J</kbd> | Show Needs Attention |
| <kbd>⌘⏎</kbd> | The bar's main action, such as Mark as Viewed or Resume |
| <kbd>⌥⌘R</kbd> | Review |
| <kbd>⌥⌘J</kbd> | Review Latest Turn |
| <kbd>⌥⌘I</kbd> | Changes panel |

## Worktrees and tabs

| Key | Action |
|---|---|
| <kbd>⌘N</kbd> | New Worktree |
| <kbd>⌘O</kbd> | Open Folder |
| <kbd>⌘]</kbd> / <kbd>⌘[</kbd> | Next / previous worktree |
| <kbd>⌃⌘1</kbd>…<kbd>⌃⌘9</kbd> | Go to worktree N |
| <kbd>⌘T</kbd> | New Tab |
| <kbd>⇧⌘]</kbd> / <kbd>⇧⌘[</kbd> | Next / previous tab |
| <kbd>⌘1</kbd>…<kbd>⌘9</kbd> | Go to tab N |
| <kbd>⇧⌘A</kbd> | Show Open Tabs |

## Closing

| Key | Action |
|---|---|
| <kbd>⌘W</kbd> | Close the pane, or the review or Settings in front |
| <kbd>⌥⌘W</kbd> | Close Tab |
| <kbd>⇧⌘W</kbd> | Close Window. Agents keep running |

## Everything else

| Key | Action |
|---|---|
| <kbd>⇧⌘P</kbd> | Command Palette |
| <kbd>⌘P</kbd> | Quick Open |
| <kbd>⌥⌘O</kbd> | All Projects |
| <kbd>⌥⌘S</kbd> | Scratch |
| <kbd>⇧⌘N</kbd> | Notification History |
| <kbd>⌘,</kbd> | Settings |
| <kbd>⌘/</kbd> | Keyboard Shortcuts |
